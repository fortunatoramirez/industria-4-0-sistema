# Lista de comprobación

## Computadora

- [ ] Node.js instalado.
- [ ] MySQL Server iniciado.
- [ ] Archivo `.env` creado.
- [ ] Contraseña de MySQL correcta.
- [ ] `npm install` terminó sin errores.
- [ ] `npm start` muestra el servidor disponible.
- [ ] Firewall permite Node.js en la red privada.

## Página web

- [ ] Se puede iniciar sesión.
- [ ] El producto está configurado.
- [ ] La caja está registrada.
- [ ] Los ESP32 aparecen en línea.

## Estación de banda

- [ ] Infrarrojo detecta una sola pieza.
- [ ] HC-SR04 mide correctamente.
- [ ] TCS34725 está bajo iluminación controlada.
- [ ] La IP y la clave son correctas.

## Estación de recepción

- [ ] Celda de carga montada correctamente.
- [ ] Factor de calibración colocado.
- [ ] RC522 lee el llavero.
- [ ] La caja está vacía durante la tara.

## Proceso

- [ ] Las piezas pasan de una en una.
- [ ] Se conserva el orden FIFO.
- [ ] La inspección cambia de esperando peso a completa.
- [ ] El inventario aumenta solamente para piezas aceptadas.
