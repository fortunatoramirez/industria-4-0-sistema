# Guía rápida para alumnos

## Servidor

1. Instalar Node.js y MySQL Server.
2. Copiar `.env.example` como `.env`.
3. Escribir la contraseña de MySQL.
4. Abrir terminal dentro del proyecto.
5. Ejecutar `npm install`.
6. Ejecutar `npm start`.
7. Abrir `http://localhost:3000`.

## Configuración

1. Entrar con el usuario definido en `.env`.
2. Editar el producto y colocar sus rangos calibrados.
3. Consultar `ipconfig` y copiar la IPv4 a los dos programas ESP32.
4. Confirmar que la clave de dispositivo coincida.
5. Cargar los programas.
6. Registrar la caja RFID.
7. Identificar la caja vacía y esperar la tara.
8. Pasar las piezas de una en una.

## Regla principal

No cambiar el orden de las piezas entre la estación de banda y la báscula.
